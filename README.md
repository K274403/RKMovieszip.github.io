# My File Index Website

This is a simple static website that lists files from a given source (such as a Telegram channel) and allows users to search for files dynamically.

## How to Use

1. Clone this repository.
2. Upload your files (or set up a script to index files) to the `files` array in `search.js`.
3. Open the `index.html` in any browser.

## Customizations

- You can modify the `files` array in `search.js` to dynamically load files from any source.
- You can style the website further by modifying the `style.css` file.
